speedrack shorts uploader — User flow (staff only)

  1. One-time setup: our staff signs in with our channel's Google account (espeedrack@gmail.com) on the Google OAuth consent screen and grants only the youtube.upload scope. The refresh token is saved as an encrypted GitHub secret.
  2. Prepare: staff produces each FAQ Short and adds it to the schedule with a title (the customer question) and description.
  3. Approve: the owner reviews each week's videos and marks them approved. Unapproved videos are never uploaded.
  4. Upload: at the scheduled time GitHub Actions runs the script: refresh token → access token → videos.insert → video is published on our channel.
  5. Log: the video ID and time are saved to youtube.json so nothing is uploaded twice.
  6. Revoke / delete: access can be revoked any time at myaccount.google.com/permissions; the token and log are deleted when we stop using the tool.
