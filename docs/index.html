speedrack shorts uploader

speedrack shorts uploader is an internal tool of SPEEDRACK Online Branch ((주)스피드랙 온라인지점). It uses the YouTube API Services (YouTube Data API v3, videos.insert) to upload our own short FAQ videos about SPEEDRACK shelving to our own YouTube channel 스피드랙온라인지점.

  • It is used only by our own staff. There are no outside users and no sign-up.
  • It uploads only videos we produced ourselves, with title and description, to our own channel.
  • It does not read, download, store or analyze any other YouTube content or any other user's data.
