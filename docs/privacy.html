2. Use of YouTube API Services

This tool uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data we access, use and store

  • We access only our own YouTube channel through Google OAuth 2.0 with the single scope https://www.googleapis.com/auth/youtube.upload.
  • We store one OAuth refresh token for our own channel as an encrypted secret in our private build system (GitHub Actions secrets). It is never shared.
  • We keep a simple log of the videos we uploaded (video ID, title, upload time).
  • We do not collect, access or store any data of other YouTube users. We do not use cookies or tracking in this tool, and we do not share or sell any data to third parties.

4. Deletion and revoking access

We delete the stored refresh token and upload log when we stop using the tool, or within 7 days of a request to espeedrack@gmail.com. Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions.
